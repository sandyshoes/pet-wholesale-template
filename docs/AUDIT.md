# 改造前审计与实施计划

审计日期：2026-10-25。范围：当前工作区全部 60 余个源文件、JSON、图片与快捷方式；读取 PHP、页面脚本、路由调用、数据库结构与聚合数量，未导出客户记录或密码哈希。

## 已实现且已验证

- 原生 HTML/CSS/JS、无前后端框架；PHP 8.2.12、MariaDB 10.4.32。本机 Apache 提供 localhost/petwebsite；PHP CLI 可用但不在 PATH。PDO MySQL、fileinfo、mbstring 可用；GD 未启用。
- 商品公共 get_products.php / get_product.php 查询 petshop.products，仅展示 status=on。上一轮曾实际验证保存、更新、下架、封面和规格读取，本轮确认接口可连接，数据库现已有真实业务数据，不能删除或替换。
- 当前全部 PHP 文件通过语法检查。这不等同于业务验收。
- 数据库有 products、admin_users、admin_login_attempts、admin_audit_logs、users、cart_items、orders、order_items、home_content 九表；实际计数：商品1、管理员1、用户1、订单4。保留现场数据。
- 当前目录及父 htdocs 都不是 Git 仓库；无远程、分支、历史或未提交差异可查，也无法证明过去未泄露敏感信息。

- 桌面与移动 CSS 已存在；未提供 Figma 文件、导出图或链接，无法验证设计像素一致性。保留暖色、圆角卡片、首页横向商品区和现有业务布局。
- 商品图片及本地猫狗图片来源无法从项目证明，须由作者确认授权。没有仓库许可证。

## 部分实现

- shop.html 分类过滤、product.html 描述/颜色/尺码/规格价格；缺关键词搜索、稳健输入校验与分页/数据状态。页面中有重复工具函数、直接插值图片 URL 风险。
- admin/products.php、product_edit.php 是真实数据库 CRUD；缺 CSRF、上传内容/大小校验、图片资源生命周期、分类管理、列表搜索及可靠错误处理。
- 两套首页内容管理，get_pdo 未定义；Index.html 是静态占位，后台与首页尚未完整连通。
- cart.html / product.html 使用 localStorage；数据库购物车另一套代码 require 不存在的根 config.php。
- checkout.html 请求不存在的 submit_order.php；订单页面请求不存在的 get_orders.php / get_order.php，有本地回退；后台 save_order.php 实际误写商品表。订单编辑引用数据库中不存在的物流字段。
- payment_create.php 按 JSON 订单号查找，不做用户所有权校验，返回 payment_result.html 占位跳转，无真实支付渠道、回调和支付校验。不能视为已收款。
- 用户登录允许明文密码回退，会话结构和 check_login.php 不一致。验证码依赖未安装的 GD。

## 风险或需作者确认

- 数据库连接硬编码 root/空密码，admin/config.php 指向另一个不存在的 petwebsite 数据库；缺生产配置与最小权限。
- data/orders.json 含收货资料；data/products.json 是旧实例商品；本地上传为实例私有资源；页面写有私人邮箱；东方财富证券交易.lnk 与网站无关。不得纳入发布包。
- 写接口无 CSRF、部分管理路径未鉴权、错误可能暴露 SQL，图片扩展名验证不足，直接 URL 插值存在 XSS 面。
- 外链 placehold.co / Unsplash 图片和本地 PNG 没有许可证据。字体为系统 Arial/Helvetica，无字体包；图标主要 Unicode/emoji，呈现依赖系统字体，不宣称拥有其字形版权。
- 没有 API 支付密钥配置；当前检索未发现有效访问令牌，但这不是凭证不存在的绝对保证。无 Git 历史可审，无法做历史泄露证明。
- 海外运营还需作者自行确认商标、隐私、税务、支付渠道、商品销售和图片使用条件；此工程不宣称完成这些业务事项。
